# Impulso

Aplicación web para gestionar compras, ventas, inventario, clientes y ganancias.

## Inicio local

```bash
npm install
npm run dev
```

Para activar sincronización con Supabase, copia `.env.example` a `.env.local`, completa las variables y ejecuta el SQL de `supabase/schema.sql` en tu proyecto Supabase.

El archivo `app-comprasventas.html` conserva el prototipo original como referencia.
